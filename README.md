# JAVA_PRACTICE

Collection of small Java practice programs and exercises. Folders include:

- `if-Else_Switch/` — examples using if-else and switch statements
- `Operators/` — operator practice
- `Variables_DataTypes/` — simple programs demonstrating variables and types (contains `one.java`)

How to compile and run a file (example for `one.java`):

```bash
javac Variables_DataTypes/one.java
java -cp Variables_DataTypes One
```
