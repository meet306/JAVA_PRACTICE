# 🚀 Java Problem Solving Practice

Welcome to my **Java Practice** repository! ☕️ 

This repository documents my journey of solving **250+ Java problems** to build strong problem-solving skills, starting from the absolute basics and progressively advancing to more complex logic and data structures.

## 🎯 Goal
The primary objective of this repository is to:
- Master Java programming concepts from the ground up.
- Improve logical thinking and algorithmic problem-solving abilities.
- Build a solid foundation for coding interviews and competitive programming.
- Consistently practice and track progress.

## 📚 What's Inside?
This collection includes solutions covering a wide range of topics:
- **Basics**: Variables, Loops, Conditionals, Methods
- **Arrays & Strings**: Manipulations, Searching, Sorting
- **Object-Oriented Programming (OOP)**: Classes, Inheritance, Polymorphism, Encapsulation
- **Data Structures**: Linked Lists, Stacks, Queues, Trees, HashMaps
- **Algorithms**: Recursion, Dynamic Programming, Two Pointers, Sliding Window

## 🛠️ Tech Stack
- **Language:** Java 
- **Environment:** JDK (Java Development Kit)

## 💡 How to Run
To run any of the solutions:
1. Clone the repository:
   ```bash
   git clone https://github.com/meet306/JAVA_PRACTICE.git
   ```
2. Navigate to the folder:
   ```bash
   cd JAVA_PRACTICE
   ```
3. Compile the Java file:
   ```bash
   javac Filename.java
   ```
4. Run the compiled class:
   ```bash
   java Filename
   ```
